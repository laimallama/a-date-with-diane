## Checks

`node maintenance/verify_project.js` verifies all thirteen generated cores against
their corresponding text games, catalogs, script syntax, Gallery leaf counts,
location regressions, and every image/effect asset. It also runs the actual adapter
and effect engine through all 47 Gallery histories in each edition using a
deterministic DOM, image-loading and clock harness. The tests assert sprite and
effect selection, cast order, independent meters, REC, language-switch continuity,
Back/replay, reduced motion, Gallery startup, Skip, and cold-load races. Independent
branch expectations cover the conditional mappings changed in this patch.

The canonical source-integrity checks separately verify 37,562 static/variant text
locations and 1,976 paired-status cases. The installed-release manifest is checked
before updating; only the thirteen visual HTML pages should change. Text releases,
wikis, transcripts and assets must remain byte-identical.

These checks do not render browser pixels or observe real GIF playback. The earlier
browser access restriction remains; no browser/server workaround was used. Actual
browser layout, device behaviour and animation timing remain unverified in this pass.
Finite regression coverage is not a claim of absolute perfection or exhaustive state
coverage, and no independent linguistic review is claimed.
